# EIP (Enterprise Information Portal) 企業資訊入口網

一個為現代企業打造的企業資訊入口網系統，整合組織架構權限、企業公告、線上簽核工作流、考勤打卡與內部資源管理。

---

## 專案簡介
EIP 旨在打破企業內部資訊孤島，提供一站式的行政與協作入口，支援多組織階層、細部權限管控 (RBAC) 與靈活的工作流簽核引擎。

### 目前已實作功能特色
- 🏢 **組織架構與 RBAC 角色**：支援多階層部門、四種角色權限體系 (`admin`, `manager`, `employee`, `hr`)。
- 🌿 **組織架構與員工維護管理後台 (Org Chart & Employee Management Hub)**：
  - **雙重視圖一鍵無縫切換 (Switchable Views)**：提供【互動視覺組織樹】與【階層清單總覽】兩種檢視模式；支援組織樹畫布 60% ~ 140% 自由縮放、一鍵 100% 重置、各節點獨立折疊/展開以及「全部展開 / 全部收合」。
  - **畫布即時模糊搜尋高亮定位 (`canvasSearch`)**：畫布頂部搜尋框支援即時輸入部門名稱、代碼、主管姓名或同仁姓名/帳號/工號，動態匹配統計筆數並自動展開所有收合節點，匹配卡片呈現琥珀色外框高亮脈衝動畫。
  - **原生拖曳調整組織階層 (Drag-and-Drop Re-parenting)**：支援滑鼠/觸控拖曳部門卡片節點至目標部門，即時調整父子隸屬關係；頂部專設「⬆️ 設為一級直屬公司部門」放置區 (Drop Zone)；前後端雙層深度遞迴循環依賴檢測，100% 絕對杜絕自環與移至子孫部門之死鎖邏輯。
  - **節點卡片快捷操作與成員指派抽屜 (Slide-over Drawer)**：卡片即時呈現部門代碼、直屬與轄下子孫部門全體總編制人數、主管頭像資訊；支援一鍵「➕ 新增子部門」（自動鎖定上級部門）、「✏️ 編輯部門」、「🗑️ 刪除部門」（員工與子部門防刪保護）；點擊同仁人數由右側滑出部門在職員工詳細名冊抽屜，落實企業標準人事作業——全面採用非原生自訂 Combobox 下拉組件，支援「輸入姓名、帳號 (Email) 或工號即時模糊搜尋選取同仁」加入或調任部門，並支援一鍵「設為主管 / 解除主管」，可隨時將成員「移出此部門」（保留帳號變更為未分配），移出主管亦自動連鎖清空主管指派。
  - **企業組織與人員編制表匯出 (Excel CSV Export with UTF-8 BOM)**：一鍵匯出全公司組織階層、負責主管、直屬在職人數、全體子部門總編制與全員工號、姓名、帳號、職稱、角色之 CSV 清冊，開頭寫入 UTF-8 BOM 徹底杜絕 Excel 亂碼，並記錄 `AuditLog` 審計留痕。
  - **部門完整 CRUD 與防刪安全保護**：支援新增/修改部門名稱、代碼、指定主管與調整排序權重；具備雙層防呆機制，若部門內尚有員工或下轄子部門，100% 嚴格阻擋刪除。
  - **員工名冊與帳號全生命週期管理**：支援多維度篩選（關鍵字、部門、角色、在職狀態），支援建立員工帳號（自動配置工號、部門、職稱、角色與初始化年度法定假別額度）、編輯人事資料、重設登入密碼。
  - **在職/停權/離職狀態維護與登入安全攔截**：同仁在職狀態切換（在職正常、暫時停權、已離職），若遭停權或離職，登入驗證層立即強制攔截並阻擋進入系統。
- 📢 **企業公告發布管理、官方附件與安全下載系統 (Announcement Publishing & Attachments Engine)**：
  - **發布管理與附件多檔上傳**：管理員與主管可透過前端視覺化彈窗 Modal 發布公告，支援拖曳上傳多個官方檢附文件（PDF、Word、Excel、圖片、ZIP，單檔上限 10MB），自動結構化存儲於 `attachments` JSON 欄位。
  - **置頂、重要度與草稿隔離保護**：支援置頂 (Pinned)、緊急度分級（低優先、一般、重要、緊急），支援存為草稿；草稿公告嚴格授權隔離（非管理員或非作者調閱或下載直接 404 阻斷防洩露）。
  - **官方附件安全下載與審計日誌**：在職同仁於詳情頁安全預覽與下載官方附件，所有下載操作完整記錄 `AuditLog` 審計留痕。
  - **連鎖推播與孤兒檔案自動清理**：發布重要或緊急公告自動連鎖全員站內通知 (`EipSystemNotification`) 與外部 Webhook 推播；下架刪除公告時自動清理磁碟實體檔案避免垃圾殘留。
- 📋 **電子表單、多層級簽核引擎與自訂表單設計器**：內建休假、報銷、加班、補打卡、設備請購、公出差旅等 6 大常用範本；主管與管理員更可透過前台視覺化設計器自由新增新表單與客製化欄位（JSON Schema），更具備**多層級簽核與條件分支引擎 (Multi-level & Conditional Workflow Engine)**：
  - 條件分支支援：請假超過 3 天自動轉派人資主管複核、費用報銷滿萬元轉派財務主管複核、滿五萬元轉派執行長決行。
  - 前端 Stepper 視覺化進度管線：清晰呈現當前各關卡狀態（已核准、審核中脈衝光、待流轉、已駁回），依關卡動態流轉。
  - 關卡搶審防護：嚴格校驗僅當前關卡之負責人與合法代理人具備審核權限，防範跨關卡越權操作。
- 🔄 **表單簽核協同加簽與轉簽派審系統 (Collaborative Workflow Engine)**：
  - **轉簽派審 (Forward/Transfer)**：主管審批時若非其管轄或需權責轉移，可將該關卡全權轉派指定主管接手；原記錄標記為 `transferred` 並保留完整交接理由，自動建立受派主管待審關卡與發送待審通知。
  - **會辦加簽 (Add-Sign)**：主管在決行前可臨時邀請跨部門主管或專家同仁會辦簽署意見；加簽人不影響主流程關卡推進與結案生命週期，會辦完成後意見自動通知並回流主審主管，由主審主管進行最終核准或裁量。
  - **全方位防呆與精準匹配**：防範自我轉簽、自我加簽與同關卡重複加簽；在多筆待審情境下優先精確匹配個人指派之加簽或主管記錄，確保簽核順暢。
- 🔁 **表單簽核退回修改與補件重新送審閉環系統 (Form Revision & Resubmission Engine)**：
  - **主管退回修改 (`revision_required`)**：審批主管若發現申請人填寫資料缺漏、佐證文件不足或請假天數需調校，可選擇「退回修改」並強制填寫具體退回指導意見；單據狀態轉為 `revision_required`、關卡記錄更新為 `returned`，休假額度維持凍結保護避免超額挪用，連鎖向申請人發送退回通知與 Webhook。
  - **前台直觀警示與即時編輯送審 Modal**：申請人進入單據詳情頁時，頂部醒目呈現琥珀色「審核主管退回修改通知」橫幅卡片，清晰展示主管退回原因；點擊「修改表單並重新提交」即可開啟彈窗，線上直接修改動態表單欄位、補充上傳證明文件（多檔上傳、單檔最大 10MB）與填寫重送說明附言。
  - **休假額度差額智慧連鎖調校**：若同仁修改請假天數，簽核引擎自動以高精度比對新舊天數差額，安全動態調校 `LeaveBalance::pending_days`（增加或釋放額度）並維持可用額度檢查，徹底杜絕透支漏洞。
  - **無縫複審重啟與完整軌跡留痕**：重送後自動為原關卡主管重啟全新待審關卡記錄並發送複審通知；前端視覺化 Stepper 管線標註「退回補件中」琥珀色脈衝光，審批歷程清晰標示「已退回修改」並保留歷次主管退回批示與申請人重送紀錄。
- 🚫 **表單申請主動撤回與複製重填機制 (Form Request Withdrawal & Re-apply Engine)**：
  - **待審單據主動撤回**：申請人本人或管理員於單據審核中 (`pending`) 可自主點擊「撤回申請」，填寫撤回原因後即時作廢單據。
  - **休假額度 100% 釋放**：若為休假單，撤回時自動解除凍結扣留額度 (`pending_days`)，可用特休與補休餘額立即全額恢復。
  - **待審記錄即時作廢與主管通知**：當前關卡待審記錄標記為 `withdrawn`，主管待審清單與首頁計數即時扣減，發送通知告知原主管無需審核。
  - **一鍵複製重新申請**：已撤回或已退件之單據，申請人可點擊「複製重新申請」，系統自動將原表單欄位內容完整預填，省時省力。
- 📎 **檢附證明文件與附件安全管理 (Proof Attachments Engine)**：支援同仁在申請請假（病假就醫證明、公假證明等）與報銷單據時，線上拖曳/選取多個附件（PDF、圖片、Word、Excel、ZIP，單檔最大 10MB）；具備嚴格水平越權 (IDOR) 防護（僅限單據申請人、審核主管、代理人與管理員可下載），所有下載操作均自動留存 `AuditLog` 審計日誌。
- 🖨️ **公文單據正式列印與 PDF 存證匯出 (Official Print View)**：專屬 A4 標準高對比度列印排版（`@media print` 自動隱藏工具列並防跨頁截斷）、完整申請人資訊、自訂明細欄位表格、檢附證明文件存證清單、多級主管審核簽署歷程軌跡、紅色雙圓框「企業電子核准防偽印章 (Official Approved Seal)」、安全雜湊序號與自動 AuditLog 稽核留痕。
- 🤝 **簽核職務代理人機制 (Delegation Engine)**：出差休假時指定同仁代理簽核、生效期間自動判定、送單時連鎖通知代理人、歷程與通知永久留痕「由代理人 XXX 代簽」之審計稽核軌跡。
- 👥 **同仁通訊錄與企業組織架構全景圖**：跨部門搜尋、分機、職稱與公務 Email 檢視；支援一鍵切換「同仁通訊名冊」與「企業組織架構圖」唯讀畫布，提供畫布縮放、模糊搜尋、節點折疊與唯讀成員抽屜。
- ⏰ **智慧 GPS 考勤打卡與 HR 月報結算 (Smart Geofencing Attendance & Analytics)**：
  - **智慧 GPS 地理圍欄 (Smart Geofencing Engine)**：整合 HTML5 Geolocation API 與 Haversine 大圓距離球面三角公式，精準計算同仁座標與公司總部直線公尺數。自動判別「辦公室內勤打卡」（圍欄內）與「外勤/遠端打卡」（圍欄外，提示填寫外勤事由）；支援未授權/無座標網段打卡防呆。
  - **視覺化後台圍欄與半徑設定 (Geofence Settings Hub)**：專屬管理員/HR設定網頁，可隨時自訂公司名稱、詳細地址、總部 GPS 中心座標與限制打卡半徑（公尺）；支援「一鍵抓取當前定位」與 Google Maps 外部快速確認，透過 SystemSetting 記憶體快取架構即刻動態生效。
  - **全遠端模式與自由打卡機制 (Full Remote Mode)**：若公司未設定經緯度座標，系統自動啟用全遠端自由打卡模式，無需設定距離限制，全體同仁自動判定為「遠端打卡」且無需強制填寫事由。
  - **超出範圍強制填寫事由機制 (Strict Reason Enforcement)**：當公司有配置圍欄且同仁處於打卡半徑外時，前端自動跳出專屬彈窗 Modal 提示填寫外勤/遠端事由，若未填寫事由前後端全面嚴格阻擋並禁止打卡，杜絕無理由外勤簽到。
  - **忘刷/補打卡單結案考勤自動同步引擎 (Attendance Regularization Sync Engine)**：當同仁提報之「忘刷/補打卡申請單 (`CLOCK_ADJUST`)」經主管核准結案時，簽核引擎自動連鎖修復或建立當日考勤紀錄，智慧正則解析出勤時間，補齊上班或下班打卡紀錄，重新計算工時並將出勤狀態校正為正常出勤 (`normal`)，自動寫入結案單號備註並留存 `AuditLog` 審計留痕。
  - **出勤紀錄異常快捷補打卡與日期自動預填**：考勤看板操作欄位針對未簽退、遲到、早退或缺卡等異常，直觀提供「申請補打卡」按鈕，點擊自動攜帶日期與參數跳轉申請，表單自動安全預填補刷日期。
  - **主管團隊出勤看板**：即時呈現今日團隊同仁上下班狀態與打卡型態（內勤/外勤/未定位）。
  - **打卡明細地圖整合**：出勤紀錄呈現 GPS 距離與型態徽章，支援點擊一鍵開啟 Google Maps 經緯度外部定位連結。
  - **HR 月報結算**：月度出勤 KPI 看板（總工時、遲到/早退人次）、員工每日打卡明細展開，支援一鍵匯出相容 Excel 之 UTF-8 BOM 格式 CSV 彙總與明細報表，下載敏感個資自動留存 AuditLog。
- 🏖️ **特休與各類假別年度額度管理系統 (Leave Balance & Quota Management Engine)**：
  - **個人年度休假概況卡片**：同仁隨時查閱年度特休假、補休、病假、事假、婚喪假、公假剩餘可用天數、上限進度條、已休與審核中凍結明細。
  - **休假申請快捷入口與個人假額存摺雙頁籤對帳表 (Dual-Tab Leave & Overtime Ledger)**：休假看板頂部提供「發起請假申請」與「申請加班換補休」快捷按鈕；額度卡片下方建立個人雙頁籤存摺對帳表（【請假支出扣額】與【加班換補休入帳】），完整追蹤每筆請假扣除、加班時數、補償方式、補休折算入帳天數（如 `+1.0 天補休`）與單據詳情連結。
  - **加班單結案自動折算補休額度引擎 (Overtime to Compensatory Credit Engine)**：同仁提交「加班申請單 (`OVERTIME`)」選擇「換取補休時數」經多級簽核核准結案時，簽核引擎自動以法定 8 小時 = 1 天標準工時將加班時數折算為天數，自動累加同仁之 `compensatory` 補休可用額度，寫入加班單號備註、發送入帳系統通知並留存 `AuditLog` 審計留痕。
  - **硬性額度管制與即時超額防呆**：特休假與補休具備硬性額度管制，填寫請假單時即時比對剩餘額度，超出天數前端動態警示、後端 100% 嚴格阻擋提單。
  - **全鏈簽核流程連鎖扣減**：休假單送出即刻凍結申請天數（`pending_days`）；主管駁回時自動解凍釋放；全流程核准結案時 DB Transaction 安全結轉為已使用額度（`used_days`）。
  - **HR / 管理員專屬配額管轄中心**：支援跨部門同仁配額表格查詢、分頁與關鍵字搜尋；彈窗支援 0.5 天精度個別調整與備註維護；提供「一鍵批次初始化全體年度法定配額」。
- ⚡ **主管審批中心與一鍵批次簽核系統 (Approvals Hub & Batch Approve Engine)**：
  - **待審單據全景看板**：集中彙整直屬待審、職務代理受託待審單據；管理者可一鍵切換「全公司所有待辦」全景視野。
  - **核心指標統計**：即時呈現「總待審批」、「今日新增」、「代理簽核」與「休假申請」等四大關鍵待辦看板卡片。
  - **多維度過濾與即時檢索**：支援表單種類過濾（請假、報銷、加班等）、審核類型切換（親自簽核 / 代理簽核）與多欄位關鍵字搜尋（申請人姓名、公文編號、申請主旨）。
  - **一鍵多選批次簽核**：支援表格全選/反選與自訂勾選；浮現頂部 Sticky 批次工具列，一鍵開啟「批次核准」或「批次駁回」對話框並填寫簽核附言。
  - **嚴密關卡流轉與越級搶審防護**：批次處理迴圈嚴格驗證每筆單據之當前關卡一致性，自動推進下一關或結案扣除休假額度，並完整記錄 `AuditLog` 批次審批審計留痕。
- 📅 **企業全景綜合行事曆看板與 iCalendar 匯出引擎 (Calendar Hub & iCalendar Export Engine)**：
  - **行事曆全景整合**：整合會議室預約排程、核准休假/差勤公文與公司重要公告日程，支援月曆標準 42 格視圖、今天快捷錨定、藍/紫/琥珀三色事件分類標籤、單一事件詳情彈窗與部門篩選。

  - **連鎖取消通知與防衝突排程**：取消會議時自動連鎖通知所有受邀與會同仁；嚴密防衝突排程防止時段重疊。

  - **分類管理與線上高畫質安全預覽引擎**：支援公司規章、表單範本、技術規格多維分類，具備同文件疊加發布新版、歷史版本歷程回溯、機密權限隔離與安全下載；實作線上高畫質安全預覽引擎（支援 PDF 內嵌翻頁閱讀、圖片自適應預覽、純文字/程式碼直接檢視、Office 檔案導航引導與全螢幕新分頁開啟），並自動記錄 `AuditLog` 預覽稽核。

- 🔔 **站內通知中心與事件推播引擎**：導覽列即時未讀通知鈴鐺與下拉摘要面板、簽核待審批/審核結果/會議預約即時通知、一鍵標記已讀與分類清單。
- ⚡ **外部通訊群組 Webhook 整合生態 (Slack / Discord / Teams)**：支援管理員設定第三方群組推播端點，簽核送單、主管審批結果、會議室借用等核心業務即時自動推播，提供 HMAC-SHA256 數位簽章防偽、雙向跨平台 Payload 相容、連線測試 Ping 與開關控制。

- ⚡ **全站快捷搜尋指揮中心 (Global Command Palette / Cmd+K 或 Ctrl+K Engine)**：
  - **跨模組平行模糊搜尋**：支援在任何頁面隨時按下鍵盤快捷鍵 `⌘K` (Mac) 或 `Ctrl+K` (Windows/Linux)，或點擊導覽列搜尋框呼出全站指揮中心；跨模組模糊檢索【同仁通訊名冊、公文單據、企業公告、會議空間、知識文庫、常用快捷導航】。
  - **嚴格授權與資安防護隔離**：通訊錄僅搜尋在職同仁（排除離職/停權帳號）；公文單據嚴格落實 IDOR 隔離（一般同仁無法探查他人私密申請單）；公告自動排除草稿與未來排程；文件嚴格遵循 `restricted_roles` 密件白名單隔離。
  - **極致鍵盤導航體驗**：輸入框具備防抖查詢 (Debounce 200ms) 與載入指示器；支援鍵盤 `↑` / `↓` 鍵循環切換選項、`Enter` 鍵直達跳轉、`Esc` 關閉視窗。
- 📝 **表單公文線上歷史版本審批對比與版本回溯 (Form History Diff & Audit Trail Engine)**：
  - **版本快照完整保存**：單據每次退回修改重新送審時，後端自動將修改前之欄位資料 (`previous_data`)、修改後之新資料 (`new_data`)、新補充之附件檔案清單 (`new_attachments`)、重送說明備註 (`resubmit_note`)、修訂時間與修訂同仁封裝為版本快照並累加存入 `revision_history`。
  - **前台直觀差異比對視窗 (Diff Viewer Modal)**：單據詳情頁面自動標註累計修訂次數，點擊「比對歷史修訂差異 (Diff)」即可開啟對照視窗，支援多版次 Tabs 切換，智慧標示每個變動欄位：紅色刪除線標註 `- 原值`，綠色粗體標註 `+ 新值`，主管審核退回件一目了然，徹底消除核對痛點。

  - **靈活配置與多維屬性**：支援管理員、主管或人資發起投票活動，支援單選/複選題型、匿名/記名機制、截止時間與動態增減選項（2~20 項）。
  - **一人一票嚴密防刷防呆**：資料庫 `poll_voters` 建立 `unique(poll_id, user_id)` 唯一索引約束，嚴密防止同仁重複投票與並發刷票。
  - **端到端匿名隱私保護架構**：匿名投票時，`poll_votes.user_id` 一律存入 `null`，投票選項與投票者身分端到端徹底解耦，即使是資料庫管理員亦無法逆向追蹤同仁具體選項，落實真正的企業匿名保障。
  - **視覺化統計與主管名冊展開**：投票結果提供動態進度長條圖 (Progress bar)、票數與百分比統計、最高票 👑 冠軍高亮徽章；若為記名投票，具管理權限者可折疊展開各選項之具名同仁名冊。
  - **生態深度整合**：工作台儀表板 (Dashboard) 內嵌活躍投票小卡、全站搜尋 (Cmd+K) 模糊檢索與全方位 `AuditLog` 審計留痕。
- 🔒 **企業級資安防禦縱深與 CI/CD Pipeline (Security Hardened Architecture)**：
  - **私有磁碟嚴格隔離 (Private Storage Isolation)**：機密證明文件與未公開公告附件全數由 `public` 遷移至 `local` 私有儲存，徹底阻絕 Nginx 靜態檔案繞過 Controller 授權之資料外洩風險。
  - **跨物件歷史版本 IDOR 防護 (Scoped Route Model Binding)**：嚴格校驗歷史版本與當前文件之一致性隸屬，杜絕跨機密文件版本越權下載與預覽。
  - **全域活躍會話即時撤銷 (Active Session Revocation Middleware)**：掛載 `EnsureUserIsActive` 全域中介層，同仁一旦被標記為停權或離職，線上活躍會話立即強制登出並銷毀 Session。
  - **垂直越權與提權阻絕 (Vertical Privilege Escalation Defense)**：嚴格限制人資帳號禁止建立或提拔最高權限 Admin 帳號。
  - **休假額度並發扣減排他性悲觀鎖 (Pessimistic Concurrency Lock)**：休假額度凍結採 `DB::transaction` 配合 `lockForUpdate()` 悲觀鎖，杜絕並發送單突破可用天數透支之 TOCTOU 漏洞。
  - **外部端點 SSRF 防護與金鑰遮罩 (SSRF Protection & Secret Masking)**：驗證 Webhook URL 嚴禁指向本機 (`localhost`)、內部私有網段與雲端中繼資料位址，並於模型層全域隱藏簽章密鑰。
  - **試算表公式注入防護 (CSV Formula / DDE Injection Sanitization)**：針對所有匯出名冊與考勤報表進行字元跳脫過濾，凡特殊字元開頭自動前綴單引號防範執行惡意公式。
  - **全面測試覆蓋**：累積 **235 項自動化 Feature / Unit 測試 100% 覆蓋通過 (1348 assertions)**，並配置 GitHub Actions 持續整合流程。

## 技術棧 (Tech Stack)
- **後端 (Backend)**: Laravel 12 (PHP 8.4-FPM)
- **前端 (Frontend)**: Inertia.js + Vue 3 + Tailwind CSS + Vite
- **資料庫 (Database)**: PostgreSQL 16 (原生 JSONB 支援動態表單欄位)
- **快取與訊息佇列 (Cache & Queue)**: Redis (Alpine)
- **Web 伺服器 (Web Server)**: Nginx (Alpine)
- **容器化 (Containerization)**: Docker Compose

## 快速啟動 (Makefile 捷徑)

專案提供便捷的 `Makefile` 指令，可直接透過 `make <目標>` 操作：

| 指令 | 功能說明 |
| :--- | :--- |
| `make init` | **初次完整啟動**（建置映像檔、啟動容器、跑遷移與假資料） |
| `make up` | 啟動所有容器服務（背景執行） |
| `make down` | 停止並移除所有容器服務 |
| `make restart` | 重新啟動所有容器服務 |
| `make ps` | 查看當前容器運行狀態 |
| `make logs` | 即時監看所有容器日誌 |
| `make bash` | 進入 `app` (PHP-FPM) 容器命令列 |
| `make test` | 執行自動化測試套件 |
| `make migrate` | 執行資料庫遷移 |
| `make seed` | 重新填入 EIP 假資料 |
| `make npm-dev` | 啟動 Vite 前端熱重載開發伺服器 |
| `make help` | 查詢所有可用指令與說明 |

### 原生 Docker Compose 指令

### 1. 啟動所有容器服務
```bash
docker compose up -d
```
服務將在背景啟動：
- **Web 前台**：http://localhost:8000
- **PostgreSQL**：`localhost:5432` (使用者: `eip_user`, 資料庫: `eip_db`, 密碼: `eip_password`)
- **Redis**：`localhost:6379`

### 2. 執行資料庫遷移與假資料填充 (初次安裝)
```bash
docker compose exec app php artisan migrate --force
docker compose exec app php artisan db:seed --force
```

### 3. 前端熱重載 (開發時可選)
```bash
npm run dev
```
若無須熱重載，Nginx 已直接提供編譯完成之靜態資源。
